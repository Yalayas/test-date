# 🗄️ База данных для приложения знакомств

## 📋 Обзор

Создана полнофункциональная база данных SQL Server 2008 R2 для веб-приложения знакомств. База данных включает все необходимые таблицы для управления пользователями, профилями, матчами, чатами и сообщениями.

## 🚀 Быстрый старт

### 1. Подключение к SQL Server
- **Сервер**: `DESKTOP-0S7BADL\SQLEXPRESS`
- **Логин**: `sa`
- **Пароль**: `123`
- **База данных**: `DatingApp`

### 2. Создание базы данных
```bash
# Откройте SQL Server Management Studio и выполните:
database/create_database.sql
```

### 3. Заполнение тестовыми данными
```bash
# После создания базы данных выполните:
database/seed_data.sql
```

### 4. Установка зависимостей Node.js
```bash
# Windows (Command Prompt)
database/install_dependencies.bat

# Windows (PowerShell)
database/install_dependencies.ps1

# Или вручную:
npm install mssql bcrypt dotenv
```

## 🏗️ Структура базы данных

### Основные таблицы

| Таблица | Описание | Записей |
|---------|----------|---------|
| **Users** | Пользователи системы | 8 |
| **UserPhotos** | Фотографии пользователей | 18 |
| **Interests** | Интересы и хобби | 20 |
| **UserInterests** | Связь пользователей и интересов | 32 |
| **Likes** | Лайки между пользователями | 12 |
| **Matches** | Взаимные матчи | 4 |
| **Chats** | Чаты для матчей | 4 |
| **Messages** | Сообщения в чатах | 12 |
| **UserSettings** | Настройки пользователей | 8 |

### Схема базы данных

```
Users (1) ←→ (N) UserPhotos
Users (1) ←→ (N) UserInterests ←→ (1) Interests
Users (1) ←→ (N) Likes (N) ←→ (1) Users
Users (1) ←→ (N) Matches (N) ←→ (1) Users
Matches (1) ←→ (1) Chats
Chats (1) ←→ (N) Messages
Users (1) ←→ (1) UserSettings
```

## 🚨 Устранение неполадок

### Проблемы подключения
1. Проверьте, что SQL Server запущен
2. Убедитесь в правильности имени сервера
3. Проверьте настройки брандмауэра
4. Убедитесь в корректности логина/пароля

### Проблемы с правами
1. Проверьте права пользователя `sa`
2. Убедитесь в настройках аутентификации SQL Server

### Проблемы с версией
- SQL Server 2008 R2 поддерживает все функции
- Для более новых версий может потребоваться обновление синтаксиса
