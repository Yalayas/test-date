# Dating App - Сайт знакомств

Современное веб-приложение для знакомств, построенное на React Native Web с использованием React Router для навигации.

## 🚀 Основные возможности

- **Регистрация и авторизация** - простая система входа с демо-данными
- **Профили пользователей** - просмотр и редактирование профилей
- **Поиск и фильтрация** - свайп-интерфейс для лайков/дизлайков
- **Чат и сообщения** - система обмена сообщениями между пользователями
- **Материалы** - просмотр взаимных лайков
- **Настройки** - персонализация приложения и приватность

## 🛠 Технологии

- **React Native Web** - для кроссплатформенной разработки
- **React Router DOM** - для навигации в веб-приложении
- **React Context** - для управления состоянием аутентификации
- **CSS-in-JS** - для стилизации компонентов
- **Webpack** - для сборки приложения
- **Babel** - для транспиляции JavaScript

## 📋 Требования

- Node.js 16+ 
- npm 8+

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd dating
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск в режиме разработки
```bash
npm start
```

Приложение будет доступно по адресу: `http://localhost:3000`

### 4. Сборка для продакшена
```bash
npm run build
```

## 🎯 Демо-режим

Приложение работает с демо-данными:
- **Демо-профили**: 4 готовых профиля для тестирования
- **Автоматическая авторизация**: используйте любой email/пароль для входа
- **Мок-данные**: чаты, сообщения и материалы генерируются автоматически

## 📱 Структура приложения

```
src/
├── components/          # Переиспользуемые компоненты
├── contexts/           # React Context для состояния
├── screens/            # Основные экраны приложения
│   ├── LoginScreen     # Экран входа
│   ├── RegisterScreen  # Экран регистрации
│   ├── HomeScreen      # Главный экран со свайпами
│   ├── ProfileScreen   # Профиль пользователя
│   ├── MatchesScreen   # Список материалов
│   ├── ChatScreen      # Список чатов
│   └── SettingsScreen  # Настройки приложения
├── App.js              # Главный компонент приложения
└── index.js            # Точка входа
```

## 🔧 Кастомизация

### Изменение цветовой схемы
Отредактируйте переменные в `src/App.js`:
```javascript
const styles = StyleSheet.create({
  appContainer: {
    backgroundColor: '#667eea', // Основной цвет
  },
  // ...
});
```

### Добавление новых профилей
Отредактируйте массив `demoProfiles` в `src/screens/HomeScreen.js`

### Изменение настроек
Модифицируйте `src/screens/SettingsScreen.js`

## 🚀 Развертывание

### Netlify
1. Подключите репозиторий к Netlify
2. Установите команду сборки: `npm run build`
3. Укажите папку: `build`

### Vercel
1. Подключите репозиторий к Vercel
2. Автоматическая сборка и развертывание

### GitHub Pages
1. Выполните `npm run build`
2. Загрузите содержимое папки `build` в ветку `gh-pages`

## 🐛 Устранение неполадок

### Ошибка "Module not found"
```bash
rm -rf node_modules package-lock.json
npm install
```

### Проблемы с портом 3000
```bash
# Укажите другой порт
PORT=3001 npm start
```

### Ошибки компиляции
Проверьте консоль браузера и терминал для деталей ошибок

## 📞 Поддержка

При возникновении проблем:
1. Проверьте консоль браузера (F12)
2. Убедитесь, что все зависимости установлены
3. Проверьте версию Node.js
